ABOUT THE GAME:

This game is a Multiplayer automation game about building Factories and extracting resources from the ground, 
by extracting them, or buying them from the local shops. Also a core part of the game
is providing (Energy)Infrastructure, to get goods from one place to another.

The World:

The Open-World consists of a Seed-based Chunk System (A known example for this would be the Game "Minecraft"). It uses so called "Surface Nets" to generate soft slopes, 
instead of blocks. The whole ground can be deformed, allowing you to mine your resources (Or build underground
facilities :D).

On the surface, there do sometimes spawn Villages, which not only provide shops and potential workers, but also
demand resources or even produce some on their own. Therefore engaging in their Wants and Needs is crucial to
your success.
